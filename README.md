# Hospital Management System (HealthCare Hospital)

A responsive, multi-page Hospital Management and Appointment Booking web application designed for patients, doctors, and hospital administrators.

---

## 🌟 Features

- **Home & Services Overview (`index.html`, `services.html`)**: Complete showcase of hospital departments, medical specialties, visiting hours, and emergency contacts.
- **Online Appointment Booking (`appointment.html`, `confirmation.html`)**: Allows patients to schedule appointments with specific specialists and receive immediate booking confirmation.
- **Doctor Directory (`doctors.html`)**: Browse doctor profiles, specialties, qualifications, and consultation schedules.
- **Patient Dashboard & Records (`dashboard.html`, `patient-records.html`)**: View appointments, personal medical history, prescriptions, and visit details.
- **Live Queue Tracking (`queue.html`)**: Monitor real-time OPD waiting list status and estimated consultation times.
- **Billing & Payments (`billing.html`)**: Patient invoice generation, payment method options, and itemized medical cost breakdown.
- **Medical Reports (`reports.html`)**: Access and download laboratory tests, diagnostic results, and physician reports.
- **Admin Management Panel (`admin.html`)**: Administrative controls for scheduling, bed allocation, and operational analytics.
- **Patient Registration & Authentication (`register.html`, `login.html`)**: Secure registration and sign-in flow.
- **Patient Feedback & Support (`feedback.html`, `contact.html`, `faq.html`)**: Dedicated channels for inquiries, complaints, and hospital FAQs.

## 🚀 Getting Started

No build step or server required! You can run this project directly in any web browser:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Keerthi-0805/Hospital-management-system.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Hospital-management-system
   ```
3. Open `index.html` in your web browser (double-click the file or right-click > *Open with* > *Chrome / Edge / Firefox*).
